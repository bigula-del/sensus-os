# Sensus OS

The management platform of **Sensus Travel DMC**: pipeline, proposals, projects, expenses, calendar, team and more,
in one place and in the Sensus identity.

## What works today
- Sign in, invitations by email and password reset
- Roles: Admin, Sales, Operations, Finance. People (HR) and Team & access are visible to the admin only
- Today page, Pipeline (add leads, open them, move them between stages) and Suppliers
- A secure client link for proposals that can never show net prices, costs or margins

## Built next
Proposal builder → project files with expenses and final margin → calendar and reminders → inbox (Office 365) →
e-signature, forms, chat, notes, marketing and the Companion app.
